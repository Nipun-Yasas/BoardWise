## PRODUCTION NOTES

### Visual Guidelines:
1. **Screen Recording Settings**:
   - Resolution: 1920x1080 (Full HD)
   - Frame Rate: 60fps for smooth transitions
   - Cursor highlighting enabled
   - Zoom in on important UI elements

2. **Transitions**:
   - Use smooth fade transitions between major sections (0.5-1 second)
   - Quick cuts for related screens (0.2 seconds)
   - Zoom transitions for emphasizing specific features

3. **On-Screen Text**:
   - Font: Clean, modern sans-serif (e.g., Inter, Roboto)
   - Size: Large enough to read comfortably
   - Duration: 3-5 seconds per text block
   - Animation: Simple fade in/out or slide in

4. **Cursor Movement**:
   - Slow, deliberate movements
   - Highlight clicked elements
   - Pause on important information (2-3 seconds)

5. **Data Privacy**:
   - Use dummy/test data only
   - Blur any sensitive information
   - Use generic names (e.g., "John Doe", "Test University")

### Audio Guidelines:
1. **Voice Characteristics**:
   - Tone: Professional yet conversational
   - Pace: Moderate (not too fast, not too slow)
   - Energy: Enthusiastic but not overpowering
   - Clarity: Clear enunciation, minimal background noise

2. **Music**:
   - Background music: Subtle, corporate/tech style
   - Volume: 20-30% of voice level
   - Mood: Upbeat, modern, inspiring
   - No music during detailed explanations (avoid distraction)

3. **Sound Effects** (optional):
   - Subtle click sounds for UI interactions
   - Gentle "whoosh" for transitions
   - Success chime for completed actions
   - Keep minimal and professional

### Timing Strategy:
- **Introduction**: 45 seconds
- **Student Features**: 5 minutes (registration to profile)
- **Owner Features**: 5 minutes (registration to profile)
- **Additional Features**: 30 seconds
- **Closing**: 30 seconds
- **Total**: ~11-12 minutes (adjust as needed)

### Post-Production:
1. **Color Grading**:
   - Enhance contrast slightly
   - Consistent color temperature
   - Highlight important UI elements with subtle glow/emphasis

2. **Captions/Subtitles**:
   - Add subtitles for accessibility
   - Use same font as on-screen text
   - Position at bottom center

3. **Logo Watermark**:
   - BoardWise logo in corner (semi-transparent)
   - Consistent throughout video

4. **End Screen**:
   - Contact information
   - Social media links
   - Website URL
   - Call-to-action buttons
   - Team credits

### Technical Checklist Before Recording:
- [ ] Test environment with dummy data populated
- [ ] All features working correctly
- [ ] Browser window cleaned (bookmarks hidden, extensions disabled)
- [ ] Screen resolution set to 1920x1080
- [ ] Zoom level at 100%
- [ ] Notifications disabled
- [ ] Dark/light mode chosen (consistent throughout)
- [ ] Recording software tested
- [ ] Microphone quality checked
- [ ] Script reviewed and practiced

3. **Match Timing**: Ensure your screen recording pace matches your voiceover pace. It's easier to slow down screen recordings than speed them up.

4. **Use Annotations**: Add subtle arrows, highlights, or circles to draw attention to important UI elements during the video.

5. **Test with Audience**: Show a draft version to someone unfamiliar with the project to ensure clarity.

6. **Brand Consistency**: Use BoardWise's actual color scheme and branding throughout any added graphics or text.

7. **Call-to-Action**: End with clear next steps for viewers (visit website, sign up, contact for demo).

   - Format: MP4 (H.264)

   - Audio: 320 kbps AAC
