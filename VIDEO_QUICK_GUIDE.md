# BoardWise Video Presentation - Quick Reference Guide

## 🎯 Quick Summary
**Purpose**: Create a video presentation showcasing BoardWise boarding management system  
**Duration**: 11-13 minutes  
**Sections**: Student Journey (5 min) + Owner Journey (5 min) + Intro/Outro (2 min)

---

## 📋 Essential Features to Showcase

### Student Side (Must-Show Features):
1. ✅ **Registration & Login** - Easy sign-up process
2. ✅ **Dashboard with Filters** - Search by university, price, distance, capacity
3. ✅ **AI Smart Recommendations** - Natural language input → Top 5 matches with scores
4. ✅ **Boarding Details** - Room listings, pricing, availability
5. ✅ **My Boarding Management** - Stay status, billing breakdown, payment tracking
6. ✅ **Stay Calendar** - Visual representation of check-in dates
7. ✅ **Billing Charts** - Monthly expense trends
8. ✅ **Profile Management** - Update personal and academic info

### Owner Side (Must-Show Features):
1. ✅ **Owner Dashboard** - Revenue analytics, trends, KPIs
2. ✅ **General Info Tab** - Create/edit boarding properties
3. ✅ **Rooms Tab** - Add rooms, upload images, manage tenants, set prices
4. ✅ **Billing Tab** - Configure bill types (electricity, water, etc.), set amounts, track payments
5. ✅ **Revenue Charts** - Yearly revenue trends
6. ✅ **Multi-Property Management** - Switch between multiple boardings
7. ✅ **Tenant Tracking** - View all tenants per room

## 🎙️ Recording Tips

### Before Recording:
- [ ] Populate test data (2-3 boardings, 4-6 rooms each)
- [ ] Create dummy accounts (student: "Alex Johnson", owner: "Sarah Williams")
- [ ] Test all features work correctly
- [ ] Set browser to 1920x1080 resolution
- [ ] Hide bookmarks and disable extensions
- [ ] Turn off notifications
- [ ] Practice script 2-3 times

### During Recording:
- [ ] Speak clearly at moderate pace
- [ ] Pause on important information (2-3 seconds)
- [ ] Move cursor slowly and deliberately
- [ ] Highlight clicked elements
- [ ] Show real interactions (typing, clicking, scrolling)
- [ ] Demonstrate filters actually filtering
- [ ] Show AI actually generating results

### Voice Guidelines:
- **Tone**: Professional but friendly
- **Pace**: 140-160 words per minute
- **Energy**: Enthusiastic but not over-the-top
- **Clarity**: Clear enunciation, minimize filler words

## 🔧 Technical Specifications

### Video Export:
- **Format**: MP4 (H.264)
- **Resolution**: 1920x1080 (Full HD)
- **Frame Rate**: 60fps
- **Bitrate**: 8-10 Mbps
- **Audio**: 320 kbps AAC, 48kHz

### Screen Recording:
- **Tool**: OBS Studio / Camtasia / ScreenFlow
- **Cursor**: Highlighted with click indicators
- **Zoom**: Enabled for UI details
- **Audio**: Separate track for easy editing

### Background Music:
- **Type**: Corporate/Tech upbeat
- **Volume**: 20-30% of voiceover
- **Avoid**: Heavy bass, distracting melodies
- **Source**: Royalty-free (Epidemic Sound, Artlist, Envato)

## ⏱️ Time Management

### If Running Long (Over 13 minutes):
**Cut or Shorten:**
- Profile sections (show briefly, don't linger)
- Repetitive navigation
- Some stat card details
- Password reset flow

**Keep Full Time:**
- AI recommendation demonstration
- Billing tab explanation
- Dashboard analytics
- Room management

### If Running Short (Under 11 minutes):
**Expand:**
- Show more boarding details
- Demonstrate more filters in action
- Show complete billing history
- Add more tenant management details
- Show mobile responsive view
